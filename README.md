# 国风色卡

一个纯前端的中国传统颜色取色板：浏览传统色、按名称或色值搜索、一键复制色值、随机生成配色组合。

## 特性

- 收录 48 个中国传统色，含名称、色值与来历备注
- 搜索：支持中文名与十六进制色值模糊匹配
- 一键复制色值到剪贴板，带提示反馈
- 「随机配色」按当前筛选结果生成 5 色方案
- 零依赖、零构建，双击 `index.html` 即可使用，也可用任意静态服务器托管

## 目录

```
index.html   页面与交互
styles.css   样式
colors.js    传统色数据
```

## 本地运行

```bash
python -m http.server 8080
```

浏览器打开 http://127.0.0.1:8080

## 技术说明

- 原生 HTML / CSS / JavaScript，无框架、无打包工具
- 颜色数据集中在 `colors.js`，新增颜色只需追加一条记录
- 使用 CSS Grid 自适应卡片布局，窄屏自动降为两列
- 复制功能基于 `navigator.clipboard`，失败时回退到临时 textarea
